# AGENTS.md

Regolith (RGL) Minecraft Bedrock addon — Script-API TPS counter. `config.json` is the source of truth; it uses the `esbuild` filter (`github.com/ink0rr/regolith-filters@0.3.1`).

## Layout

- `data/scripts/` — TypeScript source. Edit here, never the compiled output.
- `packs/BP/` — pack template (`manifest.json`, `texts/`). Script entry is `scripts/main.js`, generated by the esbuild filter from `data/scripts`.
- `ref/main.js` — gitignored reference implementation (~100 lines). `data/scripts/main.ts` is currently just a hello-world stub; port real logic from `ref/main.js` instead of inventing it.
- `build/`, `.regolith/` — generated, gitignored. Never edit.

## Commands

- Dev deploy: `regolith run` (profile `default` → `development` export)
- Local pack: `regolith run build` (profile `build` → `local` export)
- `data/scripts/tsconfig.json` is strict with `noEmit` + `noUnusedLocals/Parameters`, but no TS toolchain is vendored (no `package.json`/`node_modules`, no `tsc` on PATH). If you need a typecheck, provide your own `tsc` plus `@minecraft/server` typings matching the manifest versions below.

No tests, lint, or CI in this repo. Verification is Regolith run + in-game check.

## Gotchas

- `config.json` declares `packs.resourcePack: ./packs/RP`, but only `packs/BP` exists. This is a BP-only addon; if the build complains about the missing RP, remove/fix that key rather than scaffolding an empty RP.
- `packs/BP/manifest.json`: `min_engine_version [1,26,20]`, deps `@minecraft/server@2.10.0` + `@minecraft/server-ui@2.2.0`. Write Script API code against those versions (e.g. `system.beforeEvents.startup` custom-command registration).
- Known bugs in `ref/main.js` to fix when porting, not copy blindly: duplicate `tpsReturn` definition, typo'd `constantMontorResult`, stray `CustomCommandStatus.Success;` no-op statement, and `updateTPS` declares unused `currentTick`.
- `.agents/skills/` holds mostly JSON-UI/animation skills; this repo is a Script-API-only BP addon, so most do not apply.
